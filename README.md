## Name Inspiration

The name **Readaway** is inspired by _Sleep Away_ by **Bob Acri**.

Listen to [“Sleep Away”](https://music.youtube.com/watch?v=lHjXY6EuCc4).

## Download & Installation

Pre-built binaries are available on GitHub Releases:

| Platform    | Package     | Description                                                                      |
| :---------- | :---------- | :------------------------------------------------------------------------------- |
| **Android** | `.apk`      | Universal package or ABI-optimized builds (`arm64-v8a`, `armeabi-v7a`, `x86_64`) |
| **Linux**   | `.AppImage` | Portable standalone executable (no installation required)                        |
| **Linux**   | `.tar.gz`   | Portable bundle archive                                                          |

- **Stable Releases:** Download the latest tested version from [GitHub Releases](https://github.com/DrkXo/readaway/releases/latest).
- **Preview / Beta Builds:** Check [All Releases & Pre-releases](https://github.com/DrkXo/readaway/releases) for early access builds.
- **Integrity:** SHA-256 checksums are published in `checksums.txt` with every release.
